# QUO · Sagunt

**Proyecto de común urbano vertical** — un hub de coworking corporativo, estudio, bienestar y encuentro en las cuatro plantas del antiguo edificio de Muebles Sagunto (casco histórico de Sagunto, València).

## Estructura del repositorio

```
1. Dossier de Presentación/      → EL ÚNICO CONTENIDO QUE SE ENSEÑA.
   Nueve documentos, vocabulario unificado (glosario en 00),
   cero contenido económico — el dinero vive en Anexo Confidencial
   aparte, que aquí NO se redacta ni se almacena.
   2. Marca y Recursos/           → manual de marca, logos, material visual.
   3. Interno (no presentar)/     → herramientas de negociación, due diligence,
                                     expedientes de deal, modelos desactualizados.
                                     Nada de esta carpeta sale del círculo fundador.
   4. Archivo/                    → versiones superadas del proyecto (se conservan
                                     como registro de decisión, no como referencia).
```

## Cómo se lee esto
1. Empezar por `1. Dossier de Presentación/00_Guia-de-lectura-y-glosario.md` — define el orden y **obliga el vocabulario**.
2. Para presentar: solo la carpeta 1. El orden recomendado de entrega al Comprador: 01 → 03 → 04 → 05.

## Reglas del repositorio (convenciones)
- **Un documento maestro por idea.** Se edita el maestro, no se duplica; la versión anterior va a `4. Archivo/` con fecha.
- **Vocabulario del §00 obligatorio** en todo material nuevo (web, prensa, pitch verbal). Cambiar una palabra aprobada es un cambio de proyecto: se aprueba primero en la guía.
- **Cero dinero fuera del Anexo Confidencial** (que no vive en este repo). Los dossieres que filtran cifras antes de tiempo cambian el tipo de conversación.
- Todo dato sobre la ciudad, el edificio o la economía local que aparezca en el dossier lleva **fuente enlazada** y es verificable.
- Expedientes de deal: `3. Interno (no presentar)/Deals/NN-<nombre>/`.
